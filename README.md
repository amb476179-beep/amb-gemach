# AMB מערכות – ניהול גמ״ח

מערכת לניהול גמ״ח: לווים והלוואות, גבייה ומס״ב, התאמת דפי בנק, משימות, צ׳אט חכם לפקודות, וצ׳אט שירות לקוחות מול מנהל המערכת.

## קבצים
| קובץ | תפקיד |
|---|---|
| `index.html` | המערכת כולה (דף אחד) |
| `manifest.webmanifest`, `sw.js`, `icons/` | התקנה כאפליקציה (PWA) בטלפון, בטאבלט ובמחשב, כולל עבודה ללא רשת |
| `schema.sql` | מבנה מסד הנתונים הבסיסי ב-Neon |
| `migrations/` | שינויים במסד הנתונים לפי סדר – תוספות בלבד |

## התקנה כאפליקציה
1. ב-GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ענף `main`, תיקייה `/ (root)`.
2. אחרי דקה-שתיים האפליקציה זמינה בכתובת `https://<שם-המשתמש>.github.io/amb-gemach/`.
3. פותחים את הכתובת בטלפון: באנדרואיד/כרום – "התקן אפליקציה"; באייפון/ספארי – שיתוף ← "הוסף למסך הבית". גם בהגדרות המערכת יש כפתור "התקנת האפליקציה".

## מצב נוכחי ומה הלאה
- בגרסה העצמאית (אפליקציה) הנתונים נשמרים במכשיר. הצ׳אט בזמן אמת והעוזר החכם פועלים בגרסה שב-Claude.
- מסד הנתונים ב-Neon מוכן (כולל `migrations/002`), והשלב הבא הוא שרת API עם התחברות, כך שכל גמ״ח יעבוד מכל מכשיר ויראה רק את הנתונים והפניות שלו.
