# שרת AMB גמ״ח (Neon Functions)

API ב-`index.mjs`: התחברות עם שם משתמש וסיסמה (מוצפנת ב-bcrypt), סנכרון נתוני הגמ״ח, משתמשי צוות והרשאות, צ׳אט שירות לקוחות, טופס בקשת הלוואה ציבורי ויומן פעילות. כל גמ״ח ניגש רק לנתונים שלו; רק מנהל המערכת ניגש לכל הגמחים.

## העלאה אוטומטית
השרת עולה ל-Neon אוטומטית מ-GitHub Actions (`.github/workflows/deploy-server.yml`) בכל שינוי בתיקייה `server`, או ידנית מלשונית Actions.
נדרשים שני סודות בהגדרות המאגר (Settings → Secrets and variables → Actions):
- `NEON_API_KEY` – מפתח API של Neon.
- `SETUP_KEY` – קוד חד-פעמי ליצירת חשבון מנהל המערכת בכניסה הראשונה.

מסד הנתונים: `migrations/002` ו-`migrations/003` (תוספות בלבד) – כבר הוחלו על הענף הראשי.
