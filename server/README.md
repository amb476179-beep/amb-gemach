# שרת AMB גמ״ח (Neon Functions)

API ב-`index.mjs`: התחברות עם שם משתמש וסיסמה (מוצפנת ב-bcrypt), סנכרון נתוני הגמ״ח, משתמשי צוות והרשאות, צ׳אט שירות לקוחות, טופס בקשת הלוואה ציבורי ויומן פעילות. כל גמ״ח ניגש רק לנתונים שלו; רק מנהל המערכת ניגש לכל הגמחים.

## התקנה
1. להריץ על מסד הנתונים את `migrations/002_*.sql` ואז `migrations/003_*.sql` (תוספות בלבד).
2. `npm install && npm run build`, ואז לפרוס את `dist/index.mjs` כ-Neon Function בשם `api`, עם משתנה הסביבה `SETUP_KEY` (קוד חד-פעמי ליצירת מנהל המערכת).
3. להזין את כתובת הפונקציה ב-`API_URL` שב-`index.html`.
